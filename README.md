# Olea Coffee & Kitchen — scan-to-order menu (demo)

A QR-code menu for cafés and restaurants. Each table has its own QR code; the guest scans it,
browses the menu in their language, builds an order and sends it on WhatsApp with the table
number already written in — or keeps the list to show the waiter.

- Live demo: https://yahi264.github.io/olea-qr-menu/?t=5
- Printable table QR cards: https://yahi264.github.io/olea-qr-menu/tables.html

Features: 5 languages (EN, TR, FR, DE, AR with right-to-left layout), drink options
(size, milk, syrup, sugar, extra shot), notes for the kitchen, "call a waiter", "ask for the
bill" with payment method and bill splitting, Wi-Fi password with a join QR, and a menu assistant.

Olea is an imaginary café; photos are from Unsplash. To adapt it for a real café, edit
`assets/data.js` (name, number of tables, WhatsApp number, Wi-Fi, hours, menu and prices)
and the texts in `assets/lang/`.
